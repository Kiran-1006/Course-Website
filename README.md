# 📚 CourseLearning – Online Course Website

**CourseLearning** is a simple and interactive online course website built using **HTML, CSS, and JavaScript**.
It provides a clean interface where users can explore different courses and add their favorite courses to a shopping cart.

## ✨ Features

* 🏠 Attractive Home Page
* 📚 Multiple Online Courses
* 🛒 Add to Cart functionality
* 🔢 Increase or decrease course quantity
* 💵 Automatic total price calculation
* ❌ Remove courses from cart
* 🗑️ Clear Cart option
* 📱 Responsive design for different screen sizes
* 📦 Course data managed using JSON
* 🎨 Simple and clean user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and cart logic
* **JSON** – Course data management
* **Font Awesome** – Icons

## 📖 Courses Included

The website currently contains courses such as:

* Python Programming Mastercourse
* C++ Mastercourse
* Web Development for Beginners
* Java Programming Mastercourse
* Digital Marketing Full Course
* Web Designing Course
* Data Structures and Algorithms Full Course
* JavaScript Mastercourse

## 🛒 Shopping Cart

The website includes a functional shopping cart where users can:

1. Add a course to the cart
2. Increase course quantity
3. Decrease course quantity
4. Remove a course
5. View the total amount
6. Clear the cart

The cart quantity and total amount are updated dynamically using JavaScript.
